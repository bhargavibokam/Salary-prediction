# Employee Salary Prediction Using Machine Learning

This project predicts whether an employee earns more than $50K annually based on demographic and socio-economic data.  
We applied Logistic Regression, Random Forest, and K-Nearest Neighbors algorithms for classification.  
The dataset used is the Adult Income Dataset from the UCI Machine Learning Repository.  
Model performance was evaluated using accuracy, precision, recall, and F1-score metrics.  
Key challenges addressed include data preprocessing, handling class imbalance, and analyzing outlier impact.
